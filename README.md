**# Inventory Management System**



A Java Swing + JDBC project built in NetBeans for managing products, users, and transactions.



**## Features**

1.Add, edit, delete products

2.Manage users

3.Record transactions (IN/OUT)

4.Auto-calculate transaction totals

5.User-friendly GUI with dropdowns



**## Tech Stack**

Java (NetBeans IDE)

Swing for GUI

JDBC (MySQL)

DAO pattern
